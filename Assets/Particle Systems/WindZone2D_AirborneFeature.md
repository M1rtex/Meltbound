# WindZone2D - Airborne Boost Feature

## Что нового?

Теперь WindZone2D сильнее толкает игрока, когда он находится в воздухе (прыгает или падает)!

## Новые параметры

### Airborne Settings:
- **Airborne Multiplier** (по умолчанию: 2.0) - Во сколько раз сильнее ветер действует на игрока в воздухе
- **Ground Layer** - LayerMask для определения земли (должен совпадать с Environment Layer в PlayerMovement)

## Как это работает

1. Когда игрок находится на земле - ветер действует с обычной силой
2. Когда игрок прыгает или падает - сила ветра умножается на `airborneMultiplier`
3. Система автоматически определяет состояние игрока через метод `IsGrounded()` из PlayerMovement

## Настройка

### В префабе WindZone2D:
1. Установи **Airborne Multiplier**:
   - 1.5 - лёгкое усиление
   - 2.0 - среднее усиление (рекомендуется)
   - 3.0 - сильное усиление для экстремальных зон

2. Установи **Ground Layer**:
   - Выбери тот же слой, что используется в PlayerMovement для `environmentLayer`
   - Обычно это слой "Environment" или "Ground"

### Убедись, что у игрока:
- Есть тег "Player"
- Есть компонент Rigidbody2D
- Есть компонент PlayerMovement

## Примеры использования

### Платформинг с ветром:
```
Wind Strength: 7
Airborne Multiplier: 2.0
```
Игрок может использовать ветер для дальних прыжков!

### Экстремальная зона:
```
Wind Strength: 10
Airborne Multiplier: 3.0
Use Gust Effect: true
```
Ветер сильно сносит игрока в воздухе, создавая сложность.

### Лёгкий бриз:
```
Wind Strength: 4
Airborne Multiplier: 1.5
```
Едва заметное влияние, больше для атмосферы.

## Технические детали

- Проверка земли происходит через публичный метод `PlayerMovement.IsGrounded()`
- Если PlayerMovement не найден, используется fallback проверка через Physics2D.OverlapCircle
- Сила применяется через AddForce в OnTriggerStay2D
- AreaEffector2D работает параллельно для базового эффекта на всех объектах

## Советы по дизайну уровней

1. **Прыжковые головоломки**: Размести зоны ветра над пропастями, чтобы игрок мог использовать их для дальних прыжков
2. **Вертикальные шахты**: Восходящий ветер с высоким airborneMultiplier создаст эффект "воздушного лифта"
3. **Опасные зоны**: Сильный боковой ветер над пропастью усложнит прохождение
4. **Комбо с wall jump**: Игрок может использовать ветер между стенами для сложных манёвров
